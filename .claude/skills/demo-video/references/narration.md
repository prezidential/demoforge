# Writing narration for the ear

Target 15–30 words per scene, 6–12 seconds. Short sentences. No semicolons — a
listener cannot hear one.

## Do not describe the screen

The viewer can see the screen. Narration is for what the screen cannot say.

| Weak | Better |
|---|---|
| "Now I'm clicking on the agent to open the detail panel." | "Opening it gives you the whole picture in one panel. What it does, who runs it, and what it can reach." |
| "Here we can see the Owners tab, which lists two owners." | "Every agent needs a human answerable for it. A business owner and a technical owner, named, not implied." |
| "This is the Access Gateway creation form." | "Setting one up takes a name and a description. The hard part, enforcing policy on every call, is already built in." |

## Lead with the problem, not the feature name

| Weak | Better |
|---|---|
| "Agent Management gives you a unified inventory." | "This is the full agent inventory. Discovered automatically across every platform, so nothing runs in the dark." |
| "The Criticality field can be set per agent." | "Criticality is set on the agent itself. That rating is what the policies read when they decide how hard to push back." |

## Openings

The first line has to earn the next eighty seconds. State the problem the
audience already has, in their words.

> "Every company is deploying AI agents right now. Very few can say how many
> they have, or what those agents are allowed to touch."

Not: "Welcome to this walkthrough of our agent governance capabilities."

## Closings

One sentence, then stop. Do not summarise what was just shown.

> "Inventory, ownership, and a governed path to every tool. That is how agents
> stay accountable at scale."

## Things that read badly aloud

- **Parenthetical asides** — the voice cannot signal them
- **Long noun phrases** — "identity security posture management findings"
- **"We can see that…"**, **"As you can see…"** — filler
- **Numbers you have not earned** — do not claim "eight hundred agents" unless
  that number is on screen and true
- **Feature names as subjects** — "Access Gateway lets you…" is weaker than
  "Access gateways close that gap."

## Pacing across scenes

Each scene is generated as a separate call, so the model has no idea what came
before. Write each line to stand alone. Do not start a line with "And then" or
"Next" — it will land with the wrong intonation.

Vary sentence length between adjacent scenes. Twelve scenes of identical rhythm
is the fastest way to make a viewer stop listening.
